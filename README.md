# PyQt5-GUI-

## Electronic Fixture GUI for Operator and Engineering Debugging

A professional industrial GUI developed using Python and PyQt5 for controlling and monitoring electronic test fixtures used in manufacturing and engineering validation.

---

# Features

- Modern PyQt5 GUI
- Real-time fixture monitoring
- Serial communication support
- Automated testing workflow
- PASS / FAIL indication
- Relay and solenoid control
- Engineering debug mode
- Error handling and logging
- Industrial hardware integration

---

# Technologies Used

- Python
- PyQt5
- PySerial
- Embedded Systems
- UART Communication
- Industrial Automation

---

# Hardware Support

This GUI supports communication with:

- ESP32
- Arduino
- STM32
- PIC Microcontrollers
- Relay Boards
- Solenoid Valves
- Sensors

# Installation

Clone the repository:

```bash
git clone https://github.com/sopan02/PyQt5-GUI-.git
```

Go to project directory:

```bash
cd PyQt5-GUI-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
